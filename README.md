# 🧩 Bit Manipulation Repository

Welcome to my **Bit Manipulation** repository! This repository contains a collection of bit manipulation problems implemented primarily in **Java**. It is designed to help beginners understand bitwise operations and progress to advanced bit manipulation techniques frequently used in coding interviews and competitive programming.

---

# 📖 About

Bit Manipulation is the process of performing operations directly on the binary representation of numbers. It enables efficient solutions for many algorithmic problems by reducing time and space complexity.

This repository includes:

* ✅ Beginner-friendly bit manipulation problems
* ✅ Common interview questions
* ✅ Competitive programming techniques
* ✅ Well-commented Java solutions
* ✅ Time and Space Complexity analysis

# 🧠 Topics Covered

## 1. Bit Basics

* Binary Representation
* Even or Odd
* Check i-th Bit
* Set i-th Bit
* Clear i-th Bit
* Toggle i-th Bit

## 2. Bitwise Operators

* AND (`&`)
* OR (`|`)
* XOR (`^`)
* NOT (`~`)
* Left Shift (`<<`)
* Right Shift (`>>`)
* Unsigned Right Shift (`>>>`)

## 3. Number Problems

* Count Set Bits
* Power of Two
* Power of Four
* Count Bits
* Reverse Bits
* Number of 1 Bits

## 4. Bit Masking

* Create Bit Mask
* Set Multiple Bits
* Clear Multiple Bits
* Toggle Multiple Bits
* Extract Bits

## 5. XOR Problems

* Single Number
* Single Number II
* Missing Number
* Find Two Unique Numbers
* XOR of a Range
* Maximum XOR of Two Numbers

## 6. Subsets Using Bits

* Generate All Subsets
* Power Set
* Subsequence Generation

## 7. Advanced Bit Manipulation

* Bitwise Trie
* Maximum Subarray XOR
* Maximum Subset XOR
* Gray Code
* Divide Without Operators
